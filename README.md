# Ticket API Java 入门项目

使用 Java 21、Spring Boot、MyBatis 和 MySQL 学习工单创建、查询、取消、接单与完成，以及数据库账号和管理员用户管理。先按课件理解代码，再执行练习；各阶段验证状态见项目记录。

- 学习入口：[小白上手路线](docs/03-00-小白上手路线与操作地图.md)
- 环境与密码配置：[MyBatis 与环境配置](docs/03-03-MyBatis与环境配置.md)
- 测试、排错、打包与启停：[操作手册](docs/03-08-测试排错与部署操作手册.md)
- 当前交接：[明日检查清单](project-records/03-交接记录与明日检查清单.md)
- 项目上下文：[PROJECT_CONTEXT.md](PROJECT_CONTEXT.md)
- 文档分类：`docs/` 仅存放课件、练习与教学操作说明；`project-records/` 存放项目进度、迁移和环境验收记录。
- 空练习库建表：[带字段备注的 SQL](sql/01-schema.sql)
- 用户管理课件：[管理员、接口与会话失效](docs/03-12-用户管理：管理员、接口与会话失效.md)
- 用户管理升级：[实施与验收记录](project-records/03-用户管理实施与验收记录.md)

运行配置需提供 DB_URL、DB_USER、DB_PASSWORD。LAB_* 仅用于旧用户初始化，ADMIN_USERNAME 与 ADMIN_PASSWORD 仅用于管理员初始化脚本，不是运行时配置。数据库账号与应用登录账号不同，不把真实口令写入源码。当前代码需要完成 sql/04-user-management.sql 升级；仅执行 01-schema.sql 不足以启动完整功能。已有库先备份、检查结构并停止写入，不重复运行一次性迁移。

前端已按最新安排恢复开发，入口为同源根路径 `/`，课件见 [前端工作台](docs/03-13-前端工作台：登录、工单与用户管理.md)。历史 Windows 本地草稿仍应保留，不能覆盖。构建、数据库操作、提交和推送按用户当次授权执行，不能沿用历史授权。
