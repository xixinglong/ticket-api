- 测试、排错、打包与启停：[操作手册](docs/03-08-测试排错与部署操作手册.md)
- 当前交接：[明日检查清单](docs/03-交接记录与明日检查清单.md)

正式配置需提供 DB_URL、DB_USER、DB_PASSWORD 与四个 LAB_* 登录密码。数据库账号与应用登录账号不同，不把真实口令写入源码。已有表先检查结构，不重复建表。
